# Lucky Six

한국 로또 6/45 방식의 반응형 번호 생성기입니다. 별도 설치나 빌드 없이 브라우저에서 바로 실행할 수 있습니다.

## 실행

가장 간단한 방법은 `index.html`을 브라우저로 여는 것입니다. 로컬 서버가 필요하면 이 폴더에서 다음 중 하나를 실행하세요.

```powershell
python -m http.server 4173
```

그런 다음 `http://localhost:4173`에 접속합니다.

## 기능

- 한 번에 1~5게임 생성
- 매 게임에 포함할 고정수 최대 5개 선택
- `crypto.getRandomValues()` 기반의 편향 없는 난수 추출
- 한 게임 내 중복 방지 및 오름차순 정렬
- 개별 게임 / 전체 게임 복사 및 공유
- 최근 5회 생성 기록을 브라우저에만 저장
- 모바일, 키보드 조작, 화면 낭독기, 모션 감소 설정 대응

> 생성된 번호는 참고와 재미를 위한 것이며 당첨을 보장하지 않습니다.
